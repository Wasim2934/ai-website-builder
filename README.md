# AI Website Builder

An AI-powered full-stack website builder that allows users to generate websites from natural-language prompts, customize the generated code, and manage their projects through an interactive interface.

## 🚀 Features

- 🤖 **AI Website Generation**  
  Generate website layouts and code using natural-language prompts.

- ✏️ **Code Editing**  
  Modify and customize the generated website code.

- 👀 **Live Preview**  
  Preview the generated website while making changes.

- 🔐 **User Authentication**  
  Secure user registration and login functionality.

- 📁 **Project Management**  
  Create and manage multiple AI-generated website projects.

- 🌐 **Website Publishing**  
  Publish generated websites for easy access.

- 📱 **Responsive UI**  
  Built with a responsive interface for different screen sizes.

- ⚡ **Modern React Architecture**  
  Uses React, Redux Toolkit, React Router, Axios, and Tailwind CSS.

- 💳 **Payment Integration**  
  Stripe integration for handling payments/subscriptions.
